# Step_semester_3
## Week 9 – Practice Problems

### Problem 1: Pair Sum in a Sorted Array
- Implemented the two-pointer technique to find two numbers whose sum equals the target.
- Time Complexity: O(n)
- Space Complexity: O(1)

### Problem 2: Warehouse Bin Grid Scan
- Calculated the total number of items and identified the coordinates of the bin containing the maximum items.
- Time Complexity: O(m × n)
- Space Complexity: O(1)

### Problem 3: Library Catalog Lookup
- Implemented binary search to find a book by its ISBN in a sorted catalog.
- Time Complexity: O(log n)
- Space Complexity: O(1)

### Problem 4: Library Catalog Lookup
- Implemented binary search to retrieve a book title using its ISBN.
- Time Complexity: O(log n)
- Space Complexity: O(1)

### Problem 5: Maximum Sum Subarray of Fixed Size K
- Used the sliding-window technique to find the maximum sum of k consecutive sales values.
- Time Complexity: O(n)
- Space Complexity: O(1)
