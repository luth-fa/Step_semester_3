# Step_semester_3
## Week 10 – Practice Problems

### Problem 1: Smart Home Platform
- Implemented a smart home system using interfaces, an abstract class, and device classes.
- Used polymorphism and device command processing.

### Problem 2: Customer Registry
- Used a `HashSet` to store unique customer objects.
- Overrode `equals()` and `hashCode()` to identify duplicate customers.

### Problem 3: Student Marks Grid
- Used a two-dimensional array to store student marks.
- Calculated student totals and identified subject toppers while handling missing marks.

### Problem 4: Product Price Finder
- Used a `HashMap` to store product names and prices.
- Retrieved product prices using product names.

### Problem 5: Library Platform
- Used a `HashMap` to store and retrieve book records.
- Implemented book lookup, removal, and book count operations.
